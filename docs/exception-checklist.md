## 2. 확인할 경우 (해당하는 것만 골라 쓴다)

### 2.1 값·데이터
- [ ] **빈 값** — 빈칸, 공백만 있는 값(`'   '`), 빈 목록 `[]`
- [ ] **0개 · 1개 · 아주 많을 때** — 목록·통계·검색 결과 (0개면 빈 구역 대신 안내 또는 숨김 — EX-08·09·14·23)
- [ ] **형식이 틀린 값** — 날짜 `2026/12/1`, 없는 날짜 `2026-02-30`(`isValidYmd`), 정해 두지 않은 유형, 숫자 자리에 글자
- [ ] **겹침** — 같은 번호(id), 같은 문구(React key), 같은 DOI 중복 등록
- [ ] **너무 긴 값** — 긴 제목, **띄어쓰기 없는 긴 글자**(주소·DOI·긴 영어 — EX-24), 줄 수 제한(…). **flex 칸 안의 글자는 전체 `break-word`로 안 끊김** → `overflow-wrap: anywhere` + `min-width: 0` (B-1에서 320px 화면이 1047px로 넓어진 것 발견)
- [ ] **원본 바꾸지 않기** — 정렬·필터·수정은 새 배열·새 객체로 (React가 변화를 알아채게)

### 2.2 바깥 것 (파일·링크·외부 API)
- [ ] **그림·파일을 못 불러옴** — 파일 없음, 이름 오타 → 깨진 그림 대신 숨김 (EX-22, `onError`)
- [ ] **링크 형식** — `https://`로 시작하는지, 구글 폼 편집용(`/edit`)이 아닌지 (EX-21). 새 탭이면 `rel="noopener noreferrer"`. 성과 링크는 `safeLink`(http(s)만), DOI는 `doiUrl` (EX-30, `utils/links.ts`)
- [ ] **외부 API(Crossref)** — 형식 오류(요청 전에 막기), 없는 값(404), 네트워크 오류·응답 없음, 느림(불러오는 중 표시), 일부 정보 없음, **연타**(불러오는 동안 버튼 막기), 화면을 떠나면 요청 취소, CORS (EX-02~05·16, TC-40)

### 2.3 저장소 (localStorage)
- [ ] 읽기·쓰기 실패(막힘·용량 초과) → 앱이 멈추지 않음, 저장 실패면 화면도 안 바꿈 (EX-11·12)
- [ ] 깨진 데이터·옛 형식·번호 겹침 → 고쳐서 불러오고 안내, 원본은 백업 (2-4)
- [ ] 탭 두 개에서 동시에 수정 → 자동으로 맞춤 (EX-25, P175). 수정 중인 성과가 다른 탭에서 지워지는 경우는 아래 4절

### 2.4 날짜·시간
- [ ] **지난 날짜**, **경계 날짜**(마감일 당일은 포함인지 — EX-19는 당일까지 모집 중)
- [ ] 날짜를 받아서 계산하는 순수 함수로 만들어 **테스트에서 날짜를 바꿔 볼 수 있게** (`getRecruitStatus(r, today)`)

### 2.5 화면 (반응형)
- [ ] **1280 · 1024 · 768 · 375 · 320px** — 가로 스크롤 없음, 겹침·잘림 없음
- [ ] 한글이 단어 중간에서 끊기지 않음 + 긴 영어·주소는 칸 안에서 줄바꿈 — **글자를 감싼 버튼·flex 칸은 긴 단어만큼 넓어지므로 `overflow-wrap: anywhere`** (B-1 DOI, B-3 제목 버튼)
- [ ] 글자 끝에 붙인 아이콘(↗ 등)이 혼자 다음 줄로 떨어지지 않는지 — 마지막 글자와 줄바꿈 없는 묶음으로 (B-3, P207)
- [ ] 마우스를 올렸을 때만 바뀌는 모양은 `@media (hover: hover)` 안에 — 휴대폰은 누른 뒤 :hover가 남아 굳음. 휴대폰에서도 보여야 하는 표시는 따로 (B-3, P206–P207)
- [ ] 빈 상태·불러오는 중·오류 상태 화면이 있는지
- [ ] 장식(물방울 등)이 글자·버튼을 가리거나 클릭을 막지 않는지
- [ ] **누르는 요소 높이 44px** — 버튼만이 아니라 푸터처럼 글자만 있는 링크도 (NFR-08, 홈 점검 P187에서 푸터 22px 발견). 측정: 모든 `a[href], button`의 높이

### 2.6 주소·이동
- [ ] 없는 주소(404, EX-13), **없는 번호로 수정 주소**(EX-06), **관리 모드가 꺼진 채 관리 주소**(EX-07)
- [ ] 새로고침, 뒤로 가기, 같은 페이지 링크 다시 누르기(맨 위로)
- [ ] **뒤로·앞으로 가기로 주소가 바뀔 때** 펼친 메뉴·열린 창 같은 화면 상태가 맞는지 — 링크를 누를 때만 정리하면 남음 (EX-34)
- [ ] **`public/` 폴더 이름이 페이지 주소와 겹치지 않음** — `public/members/` 같은 폴더는 빌드 후 진짜 폴더가 되어, 배포 서버에서 `/members` 새로고침이 403이 됨. 개발 서버에서는 안 보이니 `dist`를 서버 규칙으로 흉내 내 확인 (EX-51, spec/04 점검 P268)

### 2.7 사용자 동작
- [ ] **연타** — 저장·불러오기 버튼을 여러 번 누름
- [ ] 저장하지 않고 떠남 (EX-17)
- [ ] 팝업: 닫기 3가지(X·바깥·Esc), 열린 동안 뒤 스크롤 막기 → 닫으면 되돌리기, 키보드 포커스(열면 안으로·Tab 가두기·닫으면 연 곳으로) — **공통 훅 `useModal`을 쓰면 모두 들어 있음** (1-9). 팝업마다 더 볼 것: 안에서 누르고 바깥에서 떼기(EX-28), 열린 채 페이지 이동(EX-29), 보여 주던 대상이 다른 탭에서 사라짐(EX-27), 휴대폰에서 내용이 길 때 닫기 버튼(EX-31). **걸러진 목록에서 연 팝업**은 전체 목록에서 찾기 — 다른 탭 수정으로 조건에서 빠져도 팝업 유지(EX-37, B-3)
- [ ] **누르는 범위를 덮개(`::after`)로 넓힌 줄·카드**: 덮개 위에 와야 하는 버튼(관리 수정·삭제)은 `position: relative; z-index`로 올리기, 덮개 때문에 글자를 끌어 선택하기 어려움(팝업에서 복사 가능) (B-3)
- [ ] **지우기**: 지운 뒤 포커스가 어디로 가는지(사라진 버튼에 있던 포커스는 페이지 처음으로 떨어짐 → 다음 줄·이전 줄·제목), 확인 칸이 열린 채 대상이 사라지거나 권한(관리 모드)이 꺼지면 닫기 (EX-40, B-5)
- [ ] 마우스가 없는 기기(휴대폰), "동작 줄이기" 설정
- [ ] **더블클릭** — 첫 클릭으로 화면이 바뀌면(팝업이 열림, 칸이 닫혀 줄이 줄어듦) 두 번째 클릭이 엉뚱한 곳(바깥·아래 줄)에 닿음 (spec/02 점검 P216)
- [ ] **한글 입력** — 조합 중간 글자("나벼")로도 입력 이벤트가 옴 → 입력할 때마다 결과가 바뀌는 곳은 잠깐 멈췄을 때 반영 (EX-36, 사용자 발견 P196)
- [ ] **화면 높이가 바뀔 때 좌우 흔들림** — 스크롤바가 생겼다 없어지면 폭이 바뀜 → `scrollbar-gutter: stable`로 막아 둠 (P197)

### 2.8 React · 코드
- [ ] 목록 `key`가 겹치지 않음 — **이름처럼 겹칠 수 있는 값을 key로 쓰지 않기** (같은 이름 교수, EX-52 P269)
- [ ] `useEffect`의 정리(cleanup) — 이벤트 감시·타이머·요청을 화면이 사라질 때 해제
- [ ] 개발 모드 StrictMode는 effect를 두 번 실행 → 두 번 실행돼도 문제없게 (경고·요청 중복 등)
- [ ] `any` 없이 — 모르는 값은 `unknown`으로 받아 확인 후 사용 (NFR-01)
- [ ] **저장할 때 규칙 = 불러올 때 규칙** — 한쪽만 검사하면 저장한 값이 다음 방문에 사라짐 (EX-26, P177)
- [ ] **연달아 바꾸기** — 화면이 그려질 때의 값(클로저)이 아니라 최신 값으로 계산 (같은 동작 안에서 두 번 바꿔도 어긋나지 않게, P177)
- [ ] 설정값(`lab.ts`)이 이상하면 화면은 안전하게, 개발자 도구에는 무엇을 고칠지 경고
- [ ] **오류를 던질 수 있는 함수**(`encodeURI`·`decodeURI`·`new URL`·`JSON.parse`)를 그리는 중에 쓰면 `try/catch` — 잡지 않으면 앱 전체가 하얗게 사라짐 (EX-33, 홈 점검 P187)
- [ ] **여러 파일·여러 곳을 나눠 고칠 때 순서** — 쓰는 곳(JSX)을 먼저 고치면 그 사이 개발 서버가 "없는 이름" 오류를 한 번 냄 → 가져오기(import)·변수부터 넣고 쓰는 곳은 나중에 (B-3·B-4 확인 중 콘솔에 두 번 남음). **파일 사이뿐 아니라 한 파일 안에서도 import 줄을 먼저 고친다** (E-1에 파일 순서, E-2에 한 파일 안 순서로 또 남 — P274·P280)
