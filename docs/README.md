# 기획·설계 문서

개발하면서 쓴 문서를 제출 시점(2026-11-13)에 그대로 옮긴 사본입니다.

- `PRD.md` — 문제, 사용자, 목표, 범위
- `requirements.md` — 기능·비기능 요구사항, 규칙, 예외, 인수 기준, 변경 기록
- `design.md` — 타입, 컴포넌트 계층도, 컴포넌트별 Props·상태·훅, 설계 변경 기록
- `design-visual.md` — 시각 디자인 기준과 첫 설계 초안
- `spec/` — 페이지별 상세 설계서 (요청 단위 목록)
- `test-cases.md` — 화면 테스트(TC)·단위 테스트(UT)와 결과, 요구사항 추적표
- `exception-checklist.md` — 예외 처리 점검표

문서 안의 `P###`는 프롬프트 번호, `I##`·`E##`는 개선·오류 기록 번호입니다. `report/…`와 `screenshots/…` 경로는 따로 제출하는 결과보고서 재료라 이 저장소에는 없습니다.
