## ③ 최근 성과
- **배치**: 왼쪽에 "RECENT ACHIEVEMENTS" + 제목 "새로 더해진 기록", 오른쪽에 "전체 성과 보기 ↗"(흰색) → `/achievements`. 아래에 카드
- **카드 수** (H6): **4장** (시안은 3장). 배치: 넓은 화면 4장 한 줄 / 중간 폭 2장씩 두 줄 / **휴대폰도 2×2** (P060)
- **휴대폰 카드 줄이기** (P060): 안쪽 여백 28 → 16px, 제목 20 → 16px에 **최대 3줄**(넘으면 …), 저자·학술지 줄 숨김
- **데스크톱 카드도 줄임** (P062): 4장 한 줄이면 카드 폭이 약 276px(글자 폭 약 220px)이라 긴 논문 제목은 4~5줄, 저자가 많으면 더 길어짐 → 카드 높이를 맞추려면 **제목 최대 4줄, 저자 1줄, 학술지 1줄**(넘으면 …)로 자름. 카드에는 DOI·원문 링크도 없음
  - **P288 추가**: 제목이 3줄인 카드와 4줄인 카드가 섞이면 아래 저자·학회 줄이 카드마다 어긋나서(1280px에서 31px) 사용자가 "고정시켜서 보기 편하게"(P287) → **제목 칸 높이를 4줄로 고정**(짧은 제목은 아래가 빔, 3줄 고정안보다 제목을 끝까지 보여 줌 — "4줄 고정" P288). 휴대폰은 저자·학회를 숨겨서 그대로
- **카드를 누르면 팝업** (P060–P062): 카드 전체(또는 "자세히")를 누르면 화면 가운데 팝업이 떠서 잘린 내용과 DOI·원문 링크를 보여 줌. 사용자 기준 "정보가 넘쳐서 잘릴 가능성이 있으면 넣는다"(P062)에 따라 위처럼 데스크톱에서도 잘리므로 **데스크톱·휴대폰 모두 팝업**
  - 팝업 내용: 유형 배지 · 날짜 / 전체 제목 / 저자 / 학술지·대회명 / DOI(논문이면) / 버튼 "원문 보기 ↗"(링크가 있을 때만) · "닫기"
  - 닫는 방법: X 버튼, 팝업 바깥(어두운 배경) 클릭, Esc 키
  - 팝업이 떠 있는 동안 뒤 화면은 스크롤되지 않음
  - 같은 팝업을 성과 목록(02)에서도 재사용
  - **1-9에서 더한 것 (P182)**: 예시 배지·지도교수 줄, 빈 칸은 줄째 숨김, DOI는 doi.org 링크(화면엔 번호만), 원문 링크는 http(s)일 때만. 휴대폰 팝업은 가장자리 12px만 남긴 거의 꽉 찬 화면 + 팝업 안 스크롤, 배지·날짜·닫기 줄은 스크롤해도 위에 붙어 있음(2중 점검에서 발견). 휴대폰 뒤로 가기는 팝업만 닫지 않음(한계, `docs/exception-checklist.md` 4절)
- **카드 1장**: 유형 배지 + 날짜(2026.09.15) / 제목 / 저자 · 학술지(두 줄) / "자세히 ↗"
- **데이터**: 전체 성과를 날짜 최신순으로 정렬한 앞 4개
- **동작**: 카드를 누르면 팝업으로 전체 내용 (위 참고). "전체 성과 보기 ↗"만 성과 목록으로 이동
- **예외**: 성과가 0개면 카드 대신 "아직 등록된 성과가 없어요" / 4개보다 적으면 있는 만큼만 / 저자·학술지가 없으면 그 줄을 비움
- **컴포넌트**
  - `RecentAchievementCard` — 성과 하나를 props로 받아 카드로 그림. 눌리면 부모(HomePage)에게 "이 성과를 열어 줘"라고 알림
