## 이 페이지의 목적
연구실에 **누가 있는지(재학)와 누가 거쳐 갔는지(졸업)**를 보여 준다. 부원 모집 때 "어떤 사람들이 무엇을 연구하는지" 보여 주는 데 쓴다(PRD 문제 P2). **보기만** 하는 페이지라 관리 모드·등록·수정은 없다(부원 관리는 기말 — 로그인·백엔드와 함께).

## 화면 배치 (위 → 아래, 시안 + 사용자 결정 P240)
1. **제목 줄** — 꾸밈 글씨 `MEMBERS` + 큰 제목 "부원"
2. **담당 교수 자리** (Q-D1 사용자 결정 — 시안은 지도교수를 재학 탭 카드 중 하나로 넣었지만, **탭과 상관없이 따로 늘 보이게**) — 제목 아래 가로로 넓은 카드 1장(교수가 여럿이면 여러 장): 첫 글자 동그라미 + 이름·직위("지도교수") + 연구 분야 + 학교 이메일 [AI 설계 — 시안의 카드 모양을 가로로 넓힌 것]
3. **부원 구역 머리** — 왼쪽 작은 제목 "부원" 대신 **탭** — 회색 알약 안에 "재학 4" · "졸업 2", 고른 탭은 흰 알약 + 그림자 [시안]
4. **검정 가로줄** 아래로 **부원 카드** 여러 장 — 넓은 화면 한 줄에 여러 장, 휴대폰은 한 장씩 (교수는 탭 인원 수·카드에 들어가지 않음)
3. **부원 카드** (흰 상자, 둥근 24px) [시안]
   - 위: 이름 첫 글자 동그라미(56px, 회색) + **이름**(굵게) / 그 아래 직위(작은 회색)
   - 가운데: 연구 분야(회색 글자)
   - 아래 (위에 가는 선): 왼쪽 **기간**(`2023 –`, `2022 – 2026`) / 오른쪽 **학교 이메일**(누르면 메일 쓰기, AC-15-2)
4. (지금 탭에 부원이 0명이면) `EmptyState` "아직 졸업한 부원이 없어요." 등

## 데이터
- 새 파일 `src/data/members.ts` — 고정 데이터 (요구사항 2.3, design 2절). 화면에서 고치지 않는다
- 타입 (design 2절 `Member`를 `types.ts`로): `id`, `name`, `position`(박사과정·석사과정·학부연구생…), `researchField`, `email`(학교 이메일), `status`(`'ENROLLED' | 'GRADUATED'`), **`startYear`(필수)·`endYear`(졸업만)** (Q-D2) + 예시 표시 `isSample`(Q-D1)
- **담당 교수는 따로** (Q-D1): `data/members.ts`에 `professors` 목록(이름·직위·연구 분야·이메일)을 부원 목록과 나눠 둔다 — 탭 거르기·정렬·인원 수에 섞이지 않게 [AI 설계]
- 지금은 **모두 임시(예시) 데이터** + "예시" 배지 (Q-D1). 실제 데이터(기간 포함)는 사용자가 실제 진행할 때 직접 넣음 (Q-D2, P240)
- **개인정보 (NFR-10)**: 실제 부원 이름·학교 이메일은 **본인 동의를 받은 경우에만**. 학번·개인 연락처는 넣지 않는다 → **Q-D1**
- 성과(spec/02)와는 연결하지 않는다 — 부원 이름으로 성과를 거르는 기능은 기말 후보

## 동작
- **탭**: 처음엔 "재학"(기억된 탭이 있으면 그 탭 — Q-D5). 누르면 그 상태의 부원만 보인다(AC-15-1). 탭 옆 숫자는 그 상태의 인원 수(교수 제외)
- **담당 교수 자리**: 탭과 상관없이 늘 보임. 교수 데이터가 비면 그 자리를 통째로 숨김
- 탭 키보드 동작 → **Q-D4**
- 카드 순서 → **Q-D3**
- 이메일 링크: `mailto:주소` — 누르면 메일 쓰기 창(AC-15-2). 이메일이 비어 있으면 링크를 숨김
- 새로고침하거나 다른 페이지에 갔다 오면 → **Q-D5**
