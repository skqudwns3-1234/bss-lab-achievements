# 05. 연구실 소개 (`/about`)

> 상태: **확정·구현 완료** (초안 P271 → Q-E1~E6 모두 AI 추천대로 P272 → E-1 P274 → B안 P277 → E-2 P280 → 점검 P282–P283, 2026-11-12). 아래 배치·예외는 구현 뒤 실제 모양으로 고침(P283) — 처음 계획은 괄호에 남김
> 기준 문서: `docs/requirements.md`(FR-16, Q9, AC-16-1은 Q9 결정 후 작성, NFR-07·08·10), `docs/design.md`(5.6 `AboutPage`), `src/data/lab.ts`, 체크리스트 `docs/exception-checklist.md`
> **시안 없음** — 지금 사이트의 모양(부원 페이지 구역 제목·흰 카드·홈 연구 분야 목록)을 그대로 따른다 [AI 설계]
> 마감 11-16까지 배포·보고서가 남아 있어 **요청 단위를 2개로 작게** 잡았다

## 이 페이지의 목적
처음 온 사람(지원하려는 학생, 다른 연구실)이 **"BSS가 어떤 곳이고, 어디에 있고, 어떻게 연락하는지"**를 한 페이지에서 알게 한다. 홈은 "최근 무엇을 했는지"(성과) 중심이고, 소개는 "어떤 곳인지" 중심. **보기만** 하는 페이지라 관리 모드·등록은 없다.

## 화면 배치 (위 → 아래, AI 초안 — Q-E1에서 고름)
1. **제목 줄** — 꾸밈 글씨 `ABOUT` + 큰 제목 "연구실 소개" (지금 있는 것)
2. **소개 문단** — 첫 줄은 지금 있는 "BSS는 BigdataSystemSoftware(빅데이터 시스템 소프트웨어)의 줄임말이에요." + 소개 문단 2~3개 (Q-E2)
3. **한눈에 보기** → **P276 B안: 소개 글 오른쪽(좁으면 아래) 정보 목록 4줄, 보이는 제목 없음** (처음 계획: 작은 칸 4개: 소속 학과 · 지도교수 · 재학 부원 N명 · 등록된 성과 N건 (Q-E5). 지도교수·부원 칸은 누르면 `/members`)
4. **연구 분야** — `lab.ts`의 연구 분야 (Q-E4)
5. **위치·메일·지원서** → **E-2(P279): 따로 구역 없이 3번 정보 목록에 위치 줄(건물·호실 굵게 + 아래 도로명 주소, 줄 전체가 카카오맵 "대진대학교 이공학관" 검색 새 탭)·메일 줄을 더하고, 모집 중이면 목록 아래 "지원서 작성" 버튼(푸터·홈과 같은 판단)** — 바로 아래 푸터와 같은 내용이 연달아 나오지 않게 (처음 계획: 맨 아래 "찾아오는 길·연락처" 구역)

## 데이터
- 새 데이터 없이 **지금 있는 것을 다시 씀**: `LAB`(이름·학과·위치·메일·연구 분야·모집), `PROFESSORS`(지도교수 이름), `MEMBERS`(재학 수 — `countByStatus`), 성과 목록(실제 성과 수 — 홈 통계와 같은 기준 BR-20)
- `lab.ts`에 더할 것: **소개 문단**(`about: string[]` — 줄마다 한 문단, Q-E2), 지도에 쓸 **주소**(`address`, Q-E3)
- **개인정보 (NFR-10)**: 연락처는 연구실 메일(지금은 사용자 본인 학교 메일, P113)만. 교수 전화는 부원 페이지에만 두고 여기서는 "지도교수 → 부원 페이지" 링크로 [AI 추천]

## 동작
- 한눈에 보기의 숫자는 데이터에서 계산 — 부원·성과가 바뀌면 같이 바뀜(관리 모드로 성과를 등록하면 "등록된 성과"도 늘어남)
- 지도 → Q-E3
- 지원서 작성: 홈·푸터와 같은 `recruitment.isOpen` 스위치, 새 탭
- 헤더 "연구실 소개" 현재 메뉴 점, 푸터 메뉴에서 오면 맨 위부터 (지금 있는 공통 동작)

## 확인이 필요한 사항 (사용자 결정)

**결정 (P272)**: Q-E1~E6 모두 **AI 추천대로** — "이건 추천대로 진행해도 될 것 같음". Q-E6 도로명 주소(경기도 포천시 호국로 1007)는 AI가 웹 검색으로 확인(공공데이터 가공 사이트들이 같은 주소 — 공식 홈페이지 확인은 E-2에서 사용자에게 한 번 더)
- **AI 코멘트**: 전부 이미 있는 데이터·컴포넌트를 다시 쓰는 쪽이라 새로 모을 내용이 없고, 마감(11-16) 전에 E-1·E-2 두 단위로 끝낼 수 있음. 지도 API·연혁은 기말 후보로 남겨 확장 여지도 있음
